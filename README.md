# 角色工坊 · Character Studio

本地 Electron + React 角色资料库。输入人物基础档案、选择画风和图片模型，由 Codex 补充角色设定并生成综合影视参考图。

## 运行

需要 Node.js 22+、本机已登录的 Codex CLI。选择豆包出图时需在应用设置中配置方舟 API Key 或使用 `ARK_API_KEY` 环境变量。

```bash
npm ci
npm start
```

`npm start` 会先构建再打开桌面应用。`npm run dev` 仅启动 Vite 页面服务，完整本地文件与任务能力依赖 Electron。

## 功能

- 基础档案使用一个自由输入框，案例仅作提示，无需填写固定字段。
- 支持 3D 动漫、2D 动漫、真人超写实画风。
- 支持 Codex imagegen、豆包 Seedream Flash / Pro。角色描述与设计方案始终由 Codex 整理，豆包只负责图片。
- 默认一张综合参考图，包含面部特写、全身三视图、服饰层级、配色、专属道具及三套场景穿搭；实际像素由图片模型与尺寸设置决定。
- 角色卡直接展示性别、年龄和性格关键词，并以柔粉、雾蓝、中性色边框区分性别。
- 默认女性角色在前，支持搜索、性别筛选、年龄范围筛选和排序；筛选栏可展开收起，收起后条件仍生效。
- 同名角色可保存多条参演记录，每条保留独立设定与对应图片。当前已导入资料按此结构归档；应用尚未提供通用批量导入或同名自动合并入口。
- 图片可点击放大，支持触摸板双指捏合缩放、双指滑动查看细节、原始大小、适应窗口和 Esc 关闭。
- 删除角色前确认，并将整个人物文件夹移到系统废纸篓。生成中需先取消任务。

## 本地文件

在应用中选择人物保存目录，每位角色独立保存：

- `character.json`：人物记录、标签、参演记录、任务状态。
- `角色设定.md`：角色文档。
- `assets.json`：图片清单。
- PNG 图片及独立参演档案。

本地角色资料、生成的视频、账号相关示例、应用设置与密钥不随源码提交。方舟密钥通过 Electron `safeStorage` 加密；安全存储不可用时可使用环境变量。图片模型产生的费用按各自账户计算，豆包费用不包含在 Codex 套餐内，不自动重试付费出图。

## 验证与打包

```bash
npm test
npm run build
npm run dist
```

测试覆盖目录边界、符号链接、PNG 校验、任务取消、图片请求、角色标签与筛选排序。测试使用 mock，不调用付费图片 API。

Electron 使用 context isolation、sandbox、IPC 白名单与限定人物目录的图片协议。Codex 使用 `workspace-write` 沙箱；请使用可信 CLI 可执行文件。UI 优化样式位于 `src/library-ui.css`，公共布局和其他对话框样式位于 `src/style.css`。
